Dates Admin Dashboard

Open index.html in this folder. This is a separate module; the Student app has no Admin button or login.
For web hosting, keep this folder beside the Student index.html to serve /admin/ under your deployment base. This standalone HTML may also be moved or renamed.
Sign in with the existing Editor password and a GitHub token with repository Contents read/write permission.
Save changes Test2/dbs.json only and keeps you signed in. Cancel reloads the latest saved configuration and keeps you signed in. Sign out discards unsaved edits without saving. The Student home screen refreshes settings on focus and every 15 seconds.
This module remains local; it has not been published to GitHub.
